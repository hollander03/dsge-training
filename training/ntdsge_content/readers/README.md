# DSGE and empirical-macro reading catalogue

This directory is a reference library, not a required reading list. Workshop participants should receive a short, prioritised list attached to each exercise; advanced and background material remains available for follow-up.

## 2026 core themes

| Theme | Workshop role | Recommended use |
| --- | --- | --- |
| `learning-dsge-models/` | Build intuition for what a DSGE model is for, how it links to data, and what makes a model useful for policy | Short preparatory selections and Day 4 reference |
| `identification/` | Explain the difference between a model being solvable and its parameters/shocks being empirically identified | A concise worked note linked to the DSGE exercise |
| `forecasting/` | Connect model-based forecasting, real-time data and forecast evaluation to the empirical exercises | Day 2/Day 4 extension material |
| `fiscal-policy-and-sovereign-debt/` | Supply NT-relevant policy context | Optional, question-specific reference |
| `policy-models/` | Show how policy institutions use macro models | Optional orientation material |

## Curation standard

For each workshop session, identify at most one core reading, one optional extension and one code/data resource. Do not ask participants to navigate the entire library. Published material should remain in its existing location unless permission to redistribute is clear.
