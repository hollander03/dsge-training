# RBC fiscal applications: group practical

Use the flexible-price full DSGE model supplied by the facilitator. The model and its run instructions will be added before this route is used.

There is scope for different fiscal applications. Choose one question that can be investigated in 60–90 minutes: for example, compare fiscal instruments, shock persistence, financing arrangements or policy-rule responses supported by the supplied model.

First run and understand the baseline. State your question and predict the mechanism, make one focused comparison, then interpret the result and its limitations. Keep other assumptions fixed where possible. Report the shock size, units and calibration used; distinguish impact effects from later adjustment.

Prepare a clear result and economic explanation for the group presentation. A literature review or comprehensive model description is unnecessary. Follow the [workshop presentation guidance](../../../../../admin/README.md).
