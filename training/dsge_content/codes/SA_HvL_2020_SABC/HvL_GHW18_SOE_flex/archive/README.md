# Archived specifications

`HvL_GHW18nooil_SWshocks_rep.mod` and its mode file preserve the legacy
10-observable, 10-shock flex-price model before the foreign parameter fix.
The original working source is also retained in the parent folder for reference.

`GHW2026_SOEoil.mod` and `2026_subfolder_GHW2026_SOEoil.mod` preserve the
seven-observable oil-model copies previously placed in the flex-price folders.
Despite their location, neither contains the flex-price equilibrium. They are
not the source of the corrected 10-observable model. Their comments include
unverified sample dates/settings; inspect the data and executable options.
