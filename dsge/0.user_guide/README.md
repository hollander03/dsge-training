# DSGE User Guide

This folder contains the user guide, the Dynare Manual, and additional resources to understand and implement DSGE models in Dynare. The two online base versions of **Applied DSGE Modelling with Dynare: A Practical Training Manual** are the [Google Docs version](https://docs.google.com/document/d/1mAzQPIP47KYYNsGOvcBHuVgZHptjEdJH/edit) and the [Overleaf version](https://www.overleaf.com/project/6ad72ce5d978a419cd107ac1). Maintain revisions in these online versions; the local DOCX is a downloadable snapshot. Please check the online versions before downloading. Anyone with the Google Docs link can comment.

The `archive` folder preserves the 10 December 2025 DOCX and PDF, earlier versions, the overview draft, and a copy of the Google Docs file before this revision.

*Note:* beginners for DSGE training can start with **The DYNARE software**, including installation and configuration. You can alternatively start reading the Dynare Manual (this is more comprehensive).

The `other` folder contains:
- A MATLAB primer
- A primer on linearization.
- A practical tutorial (akin to the one in the training resources).
- A description of Dynare's graph outputs
- A guide to deal with observation equations for estimation
- A guide on installing and configuring Dynare for Octave (a free MATLAB-alternative)
