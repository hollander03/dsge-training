# DSGE supporting resources

This folder contains the practical training manual and supporting resources for DSGE modelling and policy analysis. For workshop preparation, the teaching outline and practical exercises, start with the [training overview](../training/README.md).

- **[Practical Training Manual](0.user_guide):** a practical introduction to specifying, solving, estimating and analysing models in Dynare. The maintained version is available in [Overleaf](https://www.overleaf.com/project/6ad72ce5d978a419cd107ac1).
- **[MATLAB utilities](5.matlab_code):** supporting scripts for time-series processing, parameter reporting, fiscal multipliers and plotting.
- **[Example data](1.data):** data and related reference information for model applications.
- **[Policy papers](3.policy_papers):** research papers and associated replication resources.
- **[Policy applications](4.policy_analysis):** supplementary material illustrating model applications.

The guide's runnable basic RBC examples are in [`training/dsge_content/codes/Basic_RBC`](../training/dsge_content/codes/Basic_RBC).
